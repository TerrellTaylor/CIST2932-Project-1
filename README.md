# CIST2932-Project-1

Description: 
    This is a personal website that will showcase technical and communication skills as well as information organization.

Updating the site:
    To update this website, commit and sync any changes made to the files. GitHub will then take anywhere from 5-10 minutes to update the changes that have been made. It is recommended to clone the repo and use an IDE's Live feature to see changes made to the website instantly before applying them to the online version.

Technologies used:
    VSCode was used to create this website, along with Google for reminders of some HTML and CSS commands and troubleshooting. After trying to use Figma's AI tool to design the page, I realized I would rather create the website on my own, which would also help me refresh what I learned from Web Programming I. So although this website does not look very high quality, it is clear, concise, and should still meet the professional requirements.
